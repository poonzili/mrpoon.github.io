⏱️ Multi-Runner Lap Timer

Customizable Track Tracker & Pacing Charts

📖 How to Use / Instructions ▲
  1. Configuration: Set the total number of Runners and target Laps. Toggle NAPFA Mode on/off as needed. Click Initialize Track.
  2. Student Profiles: Customize names, gender, and age on each runner card. Target score brackets auto-update in NAPFA mode.
  3. Starting the Run: Click 🏁 Mass Start All for a group start, or click Start individually.
  4. Logging Laps: Click Lap each time a student crosses the finish line. Audio cues will announce progress.
  5. Pausing: Use the Pause/Resume button on individual cards for rest or mid-run adjustments. Click ⏸️ Pause All Active to pause everyone at once.
  6. Reports & Export: Click Take Snapshot at any time to generate pacing charts, time tables, and downloadable summary images.
